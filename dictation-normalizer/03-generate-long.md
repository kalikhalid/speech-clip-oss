# Промпт: длинные примеры (несколько предложений)

Добавляет в датасет длинные реплики, чтобы модель не «обрывалась» на
текстах длиннее обучающих. Формат тот же: таблица IN/OUT, без пунктуации.

```
Создай на этой странице таблицу (table / database) с двумя колонками:
"IN" и "OUT". Заполни её 40 строками ДЛИННЫХ обучающих данных по правилам ниже.

# Контекст задачи
Программа распознаёт русскую речь и записывает иностранные слова и
тех-термины русскими буквами «как слышит» (коммит, мастер, зум, джейсон).
Модель должна вернуть таким словам правильное написание (commit, master,
Zoom, .json), НЕ трогая обычные русские слова.

# Чем эти строки особенные
Каждая строка — ДЛИННАЯ: 3–6 предложений или мыслей подряд, как будто
человек надиктовывает большой кусок речи на одном дыхании.
С пунктуацией и заглавными — так, как реально выдаёт Parakeet (точки,
запятые, заглавная в начале предложений), иногда «криво».

# Что в колонках
- IN  = длинная реплика, где иностранные слова/термины написаны русскими
        буквами по звучанию, а русские слова обычные. С пунктуацией как у ASR.
- OUT = та же реплика, где термины записаны правильно, русские слова
        БЕЗ ИЗМЕНЕНИЙ. ТА ЖЕ пунктуация и регистр сохраняются 1:1.

# Железные правила
1. Русские глаголы, предлоги, союзы НИКОГДА не переводи на английский.
   «сделай коммит» → «сделай commit» (НЕ «make commit»).
2. Меняется ТОЛЬКО написание термина. Порядок слов сохраняется один в один.
3. Пунктуация и регистр сохраняются 1:1 между IN и OUT (как у ASR);
   меняется только написание термина, точки/запятые/заглавные не трогаем.
4. ИМЕНА ФАЙЛОВ в OUT пиши через собачку @, без code-форматирования:
   ридми точка эм дэ → @README.md ; пакедж джейсон → @package.json ;
   карго томл → @Cargo.toml ; точка энв → @.env
5. Прочие термины (команды, бренды, сервисы) — обычной латиницей без @:
   commit, docker compose, Zoom, Figma, API.
6. Один и тот же термин в разных строках озвучивай ПО-РАЗНОМУ
   (commit → коммит / комит; remote → ремот / римоут).

# Фантазируй и бери слова из РАЗНЫХ сфер
Не ограничивайся программированием. Придумывай живые длинные монологи из
любых сфер где в русской речи проскакивают иностранные слова: разработка
git docker файлы тесты деплой, рабочие инструменты Zoom Slack Notion Figma
Excel Jira, бренды YouTube iPhone Telegram, аббревиатуры API URL SQL PDF KPI
и любые другие сферы. Фантазируй свободно.

# Состав 40 строк
- 34 строки: длинные реплики с терминами из разных сфер (3–6 предложений).
- 6 строк: длинные реплики из ЧИСТО русской речи без иностранных терминов —
  IN и OUT полностью одинаковые.

# Разнообразие
Меняй сферы темы длину и тон. Не повторяй однотипные монологи.

# Вывод
Только таблица с колонками IN и OUT, без пояснений до или после.
```
