# AGENTS.md

## О проекте
Speech Clip OSS — приватная локальная голосовая диктовка для macOS.
Tauri 2 + Rust (бэкенд) и SvelteKit + Svelte 5 (фронт). ASR (Parakeet TDT 0.6B v3)
и нормализатор (Qwen 0.8B через llama.cpp) работают on-device, без облака.
Это production-код: пользователи запускают приложение каждый день. Меняй осторожно.

Главная активная работа — нормализатор русской диктовки. Прежде чем трогать
AI/датасет, прочитай `dictation-normalizer/README.md` (архитектура двух слоёв,
над чем работаем, где данные).

## Приоритеты при написании кода (в порядке важности)
1. БЫСТРОТА — это самое важное. Код в hot-path (ASR → нормализация → вставка)
   обязан быть быстрым. Меряй, не угадывай. NEVER добавляй задержку в путь диктовки.
2. ЭФФЕКТИВНОСТЬ — минимум аллокаций и копий, не клонируй без нужды (предпочитай
   `&str`/срезы), не делай работу повторно, не блокируй async-поток на CPU/IO.
3. ЧИСТОТА — простой, читаемый код. Пиши так, как написан окружающий код:
   те же имена, идиомы, плотность комментариев. Маленькие функции, явные типы на
   границах. NEVER оставляй мёртвый код, закомментированные блоки или TODO-заглушки.

## Правила
- ALWAYS: перед коммитом `cargo fmt` и `cargo clippy` чисто; `bun run check` для фронта.
- ALWAYS пиши тесты на детерминированную логику (правила нормализации, парсинг).
  Запуск: `cargo test`.
- MUST: детерминированную обработку держи в правилах (`spoken_normalization.rs`),
  на LLM оставляй только то, что правила не решают. Не дублируй одно в двух местах.
- NEVER коммить секреты/ключи (OPENAI_API_KEY и т.п.) и большие модели в git.
- NEVER переводи русские слова на английский в нормализаторе — чинятся только термины.
- Стиль кода — за `rustfmt`/`clippy`/`prettier`. Не описывай стиль текстом, просто следуй.
- Коммить/пушь только по просьбе. Ветку от main создавай перед PR.

## Как отвечать
- Кратко, чётко, без воды. Сразу к сути, без преамбул и пересказа вопроса.
- NEVER расхваливай и не лей общие слова. Конкретика > вежливые обороты.
- Не объясняй очевидное и не повторяй уже сказанное. Длина ответа = по делу.
